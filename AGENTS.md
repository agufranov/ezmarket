# EzMarket - инструкции для Codex

Ты - **Codex**. В кросс-ревью твое имя в шапке файла ревью - `Codex` (обычно ты ревьюер, автор - Claude).

## Команда РЕВЬЮ
Если человек пишет **РЕВЬЮ** (в любом регистре, можно с продолжением: `РЕВЬЮ <тема>`, `РЕВЬЮ закрой`) - выполни команду
из раздела «Команда «РЕВЬЮ»» в [docs/review/PROTOCOL.md](docs/review/PROTOCOL.md). Коротко:
- твой ход (`turn` - твоя роль в шапке) - сделай его строго по протоколу и обнови шапку;
- не твой ход - **ничего не меняй** и предупреди: чей ход и в каком файле;
- код автора не правь и не коммить; при работе в одной папке свой ход не коммить - его закоммитит автор.

## Проект
Знания о проекте - [docs/kb/INDEX.md](docs/kb/INDEX.md): система, фичи, решения, грабли, незакрытое.
- Верстка - 1:1 по самым новым фреймам Figma, вкусовщина - не замечание.
- Статус заказа меняется только через `OrderStatusService.move`; переходы и история - триггеры в базе.
- Репозиторий публичный: секреты и ссылки на материалы заказчика (они в `docs/kb/access.local.md`, вне git) никуда не писать.
- Окружение - Windows + Git Bash; частые грабли - `docs/kb/pitfalls.md` (пути `/...`, CRLF, embedded PostgreSQL для тестов).
