# База знаний EzMarket

Файловая база знаний о проекте: что где лежит, как устроено, почему так решили и на какие грабли уже наступали.
Читать с этого индекса, дальше - нужный файл. Обновлять в том же коммите, что и изменение, о котором речь.

> Репозиторий **публичный**. Сюда - только то, что можно показать всем. Ссылки на макет, ТЗ, план недели,
> адрес и вход на стенд, токены - в `access.local.md` (в git не попадает, см. `.gitignore`).

| Файл | О чем |
|---|---|
| [access.local.md](access.local.md) | **Не в git.** Доступы: Figma, ТЗ и план недели (Google Docs), стенд, Crypto Pay. Образец - [access.example.md](access.example.md) |
| [system.md](system.md) | Стек, структура репозитория, режимы запуска (Docker, `npm run local`, моки), порты, переменные окружения, CI |
| [workflow.md](workflow.md) | Как работаем: верстка 1:1 по макету и дешевая сверка, ветки и коммиты, тесты, выкладка на стенд |
| [features/frontend.md](features/frontend.md) | Главная и модалки: что сделано, где источник истины в макете, поддержка у виджета, плашка Steam, страница заказов |
| [features/auth.md](features/auth.md) | Вход по коду из письма: правила, сессии, демо-режим |
| [features/orders.md](features/orders.md) | Заказ пополнения Steam: статусы и переходы, история, ключ повтора, истечение, выполнение, API |
| [features/payments.md](features/payments.md) | Оплата: тестовая платежка и Crypto Pay, подпись уведомлений, опрос, истечение и отмена со счетом |
| [features/bonuses.md](features/bonuses.md) | Бонусы: регистрация, оплата до 30% заказа, возврат, кэшбэк 5%; списание без гонок, триггер возврата и начисления, история, API |
| [decisions.md](decisions.md) | Принятые решения и почему (статус в заказе + история триггером, суммы в копейках, лимиты с бэкенда...) |
| [pitfalls.md](pitfalls.md) | Грабли: Figma MCP, браузеры, часовой пояс базы, Windows и Git Bash, Prisma, Next export, всплывающие окна |
| [todo.md](todo.md) | Временное и незакрытое: что вернуть, что не сделано, открытые вопросы к заказчику |
| [../review/PROTOCOL.md](../review/PROTOCOL.md) | Кросс-ревью двух нейросетей: роли, ходы, формат замечаний и ответов, файлы ревью в `docs/review/threads` |
