# Сверка верстки с макетом

Скрипты для проверки экрана целиком против кадра Figma. Выгрузка макета (`figma.xml`) и тексты кадров (`*.json`) -
материалы заказчика: лежат здесь только локально, в git не попадают (`.gitignore`).

## Подготовка
1. Выгрузка `get_metadata` Figma MCP для страницы `0:1` -> `figma.xml` в этой папке (один вызов, лимит MCP маленький).
2. Тексты нужных кадров с абсолютными координатами:
   `node figma-texts.mjs figma.xml figma-texts.json 38:70 38:1032 24:17 ...`
3. Раздать папку странице: `node serve.mjs` (127.0.0.1:3031, CORS).

## Что проверять на каждом кадре
1. **Тексты** - в консоли страницы нужной ширины (360 / 440 / 1920):
   `const { cmp } = await import("http://127.0.0.1:3031/cmp.mjs"); await cmp("38:70", { tol: 2 })`
   На 1920 сначала убрать полосу прокрутки (`html { scrollbar-width: none }`), иначе все съезжает на 7 px.
2. **Декоративные фигуры** - круги, пятна, кольца, «капли» без текста, выступающие за край блока. Текстами их не поймать.
   - Список в макете: `node deco.mjs figma.xml 38:70 24:17 ...` (размер и место от родителя).
   - Для каждого типа фигуры прочитать в панели свойств Figma (`?node-id=...`, без Dev Mode) **цвет, прозрачность
     заливки и прозрачность слоя (Opacity)**, скругление, обводку. Прозрачность слоя стоит отдельной строкой -
     ее пропуск дал яркий полукруг вместо едва заметного пятна в каталоге (12:1035, 60%).
   - На странице: `const { decoDom } = await import("http://127.0.0.1:3031/decodom.mjs"); decoDom()` - те же фигуры
     с размером, местом, цветом и opacity. Сравнить построчно; лишние фигуры, которых нет в макете, убрать.
   - Если фигура в разных кадрах разного размера, проверить пропорцию: обложки карточек в макете заданы долями
     (кольцо 70% ширины и т.д.), фиксированные px с десктопа на мобилке дают круги вдвое больше.
3. **Повторяющиеся элементы** (карточка, чип цены, плашки «хит» и скидки) - панель каждого слоя одной карточки:
   размер, скругление каждого угла, заливка, тени внутрь и наружу, кегль, жирность, высота строки, цвет. Потом снимки
   макета и страницы в PNG (`zoom` в одном и том же Chrome) и цвета в одних и тех же точках - фон, градиент, фигуры.
4. **Состояния** - наведение, активный пункт, открытые панели: свои слои и свои фигуры (блик на чипе цены
   у товара под курсором и т.п.). Сверять каждое состояние, что есть в макете.
5. **Поля ввода** - плейсхолдер и значение не текст страницы: ширину поля и отступ текста мерить отдельно.
6. **Горизонтальный скролл** - `overflow.mjs` на 360 / 375 / 414 / 480 / 600 / 767.
7. **Глазами** - кадр Figma и страница рядом, увеличение от 200%: цвета, тени, градиенты.

`figma-tree.mjs <figma.xml> <frameId> <nodeId> [depth]` - поддерево слоя с абсолютными координатами.
Огрехи выгрузки, которые не повторяем, и прочие грабли - `docs/kb/pitfalls.md`.
