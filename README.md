# EzMarket - главная страница

Next.js 15 (App Router), TypeScript, SCSS-модули.

## Запуск

Нужен Node 22 LTS (версия в `.node-version`).

```bash
npm install
npm run dev     # http://localhost:3000
npm run build && npm start
```

## Структура

- `src/app/globals.scss` - дизайн-токены из ТЗ (цвета, скругления, тени, слои, тайминги), базовые стили
- `src/styles/_mixins.scss` - брейкпоинты и миксины
- `src/components/sections` - секции главной и шапка (каталог, поиск, валюта, профиль, уведомления, пузырь гостя)
- `src/components/auth` - окно «Вход / Регистрация»
- `src/components/support` - поддержка у виджета: меню, частые вопросы, «Написать нам», экран успеха
- `src/components/ui` - переиспользуемые компоненты
- `src/lib/modal.tsx` - каркас модалки и `openModal(name)`; `src/lib/auth.tsx` - авторизация на моках
- `src/config` - ссылки (`routes.ts`), тайминги и лимиты (`site.ts`), валюты, провайдеры входа
- `src/data`, `src/services` - моковые данные и запросы до подключения API (места запросов помечены `// API:`)

## Демо-состояния

- `?auth=1` - войти мок-пользователем, `?auth=0` - выйти (или любая соцсеть в окне входа / «Выйти» в профиле)
- `?auth=1&notif=0` - пустые уведомления «Пока тихо»
- в форме «Написать нам» текст `error` - ошибка отправки; email `error@…` в окне входа - ошибка отправки кода
- промокоды для регистрации: `EZ100`, `FRIEND-2026`, `WELCOME`

## Статус

Десктоп от 1024 px. Мобильная версия - после мобильных макетов. Шаг «Ввод кода» - после макета.
